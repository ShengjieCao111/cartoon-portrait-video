# 人像分割+背景替换+漫画风格视频生成
基于昇腾ACL实现实时人像分割、背景替换与漫画风格转换系统，支持摄像头实时采集并生成二次元风格视频。

## 项目简介
本项目为昇腾AI计算机视觉综合实训项目，基于Python、OpenCV与Ascend ACL推理框架开发，包含三项核心功能：
1. 实时人像分割：从摄像头画面精准提取人像前景区域；
2. 自定义背景替换：依托分割掩码完成人像与自定义背景无缝融合；
3. GAN漫画风格转换：将融合图像实时转换为二次元漫画效果。
项目完整覆盖AI离线模型推理、实时视频流处理、图像融合全流程，是昇腾NPU多媒体视觉落地实践案例。

## 核心功能与实现流程
1. 实时人像分割
采用 portrait.om 离线模型，读取摄像头画面，完成图像解码、尺寸预处理后送入 NPU 推理，输出人像分割掩码，区分前景人像与背景。
2. 自定义背景替换
基于模型输出的人像掩码，对原图与背景素材做像素加权融合，实现人像与新背景无缝拼接。
3. GAN 漫画风格转换
调用 generatorv2.om 漫画生成模型，完成图像通道转换、归一化预处理，推理后还原原图尺寸，输出稳定漫画风格画面。
4. 视频录制与结果输出
程序自动录制原始画面与风格化处理视频，保存至 out/result 目录，支持自定义录制时长。

## 项目运行步骤
部署完成 Ascend ACL 开发环境，安装全部第三方依赖；
将背景图片 background.jpg 放入 data 文件夹；
将人像分割、GAN 模型文件放入 model 文件夹；
打开 Test.ipynb，执行全部代码块；
程序自动调用摄像头，实时展示处理后的画面；
录制结束后，在 out/result 目录查看原始视频与漫画成品视频。

## 运行效果
程序运行时实时输出处理画面，自动完成换背景与漫画风格转换；程序结束输出两份对比视频。依托昇腾 NPU 硬件加速，画面推理流畅，无明显卡顿延迟。

## 项目难点与解决方法
1.模型推理格式适配
难点：原图格式、尺寸与 ACL 模型输入标准不匹配
方案：统一封装图像 JPEG 转 YUV、输入尺寸对齐预处理逻辑
2.人像边缘融合生硬
难点：单通道掩码无法直接适配三通道图像融合
方案：将掩码扩展为三通道，调整像素融合权重优化边缘过渡
3.漫画画面连续帧抖动
难点：前后处理参数不统一导致风格波动
方案：固定 GAN 模型归一化、反归一化映射区间，统一预处理流程
