# 🎨 人像分割 + 换背景 + 漫画风格视频生成

> 基于 Ascend ACL 实现的实时人像分割、背景替换与漫画风格转换系统，支持摄像头实时录制并生成二次元风格视频。

---

## ✨ 项目简介

本项目为计算机视觉与昇腾 AI 综合实训项目，基于 **Python + OpenCV + Ascend ACL** 开发，实现三大核心功能：

| 功能 | 描述 |
|------|------|
| 🧍 实时人像分割 | 从摄像头画面中精准提取人像区域 |
| 🖼️ 自定义背景替换 | 自动融合用户指定背景图片 |
| 🎨 漫画 GAN 风格转换 | 将融合后的画面实时转为二次元漫画效果 |

项目完整覆盖了 AI 模型推理、视频处理、图像融合的全流程，是昇腾 NPU 开发在多媒体处理领域的典型实践。

🚀 核心功能与实现流程
1️⃣ 实时人像分割
模型：portrait.om（人像分割模型）

流程：摄像头帧读取 → JPEG 解码 → 尺寸调整 → 模型推理 → 生成人像掩码

作用：精准区分前景人像与背景，为后续融合提供依据

2️⃣ 自定义背景替换
原理：基于人像掩码，将背景图片与原画面按权重融合

效果：自动替换原始背景，实现人像与新背景的无缝拼接

3️⃣ 漫画 GAN 风格转换
模型：generatorv2.om（漫画 GAN 生成器）

流程：BGR→RGB 转换 → 尺寸归一化 → 模型推理 → 反归一化 → 恢复原尺寸

效果：将人像画面转为二次元漫画质感，线条清晰、色彩明快

4️⃣ 视频录制与结果输出
自动录制原始视频与处理后视频，保存至 out/result 目录

支持自定义录制时长，一键生成成品视频

📌 项目难点与解决方法
难点	解决方法
模型推理适配	针对 Ascend ACL 框架，实现图像格式转换（JPEG→YUV）与尺寸对齐
背景融合优化	通过掩码反转与三通道扩展，解决边缘融合生硬的问题
漫画效果稳定	调整 GAN 模型预处理/后处理流程，避免风格抖动
